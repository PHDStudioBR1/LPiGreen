# **App Name**: iGreen Saver

## Core Features:

- Hero Section with Lead Capture: Eye-catching hero section with headline, sub-headline, and a prominent CTA button to initiate the eligibility test via a modal form.
- Authority Proof Section: Display logos of major news outlets to establish credibility regarding rising electricity costs.
- How It Works Section: Cards explaining the iGreen Energy model compared to traditional energy distributors.
- Interactive Savings Simulator: Slider-based simulator allowing users to input their current bill and see projected monthly and annual savings. Updates automatically with user input.
- Scarcity and Urgency Indicator: Progress bar displaying the percentage of available slots filled, emphasizing limited availability.
- Social Proof via Testimonials: Video and text testimonials from satisfied customers showcasing their savings.
- FAQ Section: Accordion-style FAQ to address common objections and build trust.
- Firebase Integration: Form to capture user data (Name, WhatsApp, CEP, Average Bill Value) with preconfigured integration with Firebase Firestore for data storage.

## Style Guidelines:

- Primary color: Emerald Green (#50C878) for trust and sustainability.
- Background: Light Gray (#F2F2F2) for a soft and clean aesthetic.
- Text: Charcoal Gray (#333333) for optimal legibility.
- Font: 'Inter' (sans-serif) for body and headline text, to maintain a modern, neutral look.
- Clean, minimalist icons related to energy savings and sustainability.
- Modern, clean layout with 'Glassmorphism' effects on floating cards, soft shadows, and rounded corners for a premium feel.
- Subtle hover effects on buttons (scale and glow), smooth transitions on scroll, and a gently pulsing WhatsApp button to grab attention.
